♻️ ECODROP

🚀 Overview

EcoDrop is a waste management platform that connects:

* 🧑‍💼 Sellers (who have recyclable waste)
* ♻️ Recyclers (who collect waste)
* 🛠 Admin (who manages the system)

---

🛠 Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express

---

📂 Project Structure

ECODROP/
├── Backend/
├── Frontend/
├── README.md

---

⚙️ Setup Instructions

Backend

cd Backend
npm install
npm start

Frontend

Open index.html in your browser

---

📌 Features

* User Authentication (Login/Signup)
* Seller Dashboard
* Recycler Dashboard
* Admin Dashboard
